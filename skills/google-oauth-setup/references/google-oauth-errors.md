# Google OAuth Setup — Error Transcripts & Resolution Recipes

## Error 1: access_denied / "developer hasn't given you access"

**Full error URL (URL-decoded)**:
```
https://accounts.google.com/signin/oauth/error?authError=Cg1hY2Nlc3NfZGVuaWVkEs4BVGhlIGRldmVsb3BlciBoYXNu4oCZdCBk...
```

**Message**: *"The developer hasn't given you access to this app. It's currently being tested and hasn't been verified by Google."*

**Cause**: OAuth consent screen is in "Testing" mode and user's email is not in the Test Users list.

**Fix**:
1. Go to https://console.cloud.google.com/auth/audience
2. Under "Test users", click "ADD USERS"
3. Add `hansaxel25@gmail.com`
4. Save
5. Re-run `$GSETUP --auth-url` to get a fresh URL
6. Visit the new URL and authorize again

## Error 2: Gmail API not enabled

**Transcript**:
```
googleapiclient.errors.HttpError: <HttpError 403>
"Gmail API has not been used in project 581943771814 before or it is disabled.
Enable it by visiting https://console.developers.google.com/apis/api/gmail.googleapis.com/overview?project=581943771814"
```

**Cause**: API was either never enabled, or was enabled too recently and Google's systems haven't propagated yet.

**Fix**:
1. Visit the URL from the error message
2. Click "Enable"
3. Wait 2-3 minutes
4. Retry the API call

## Error 3: setup.py --auth-url with wrong flags

**Transcript**:
```
usage: setup.py [-h] (--check | --check-live | --client-secret PATH | --auth-url | --auth-code CODE | --revoke | --install-deps)
setup.py: error: argument --auth-url: not allowed with argument --client-secret
```

**Cause**: Trying to run multiple mutually exclusive flags at once.

**Fix**: The script has a `mutually_exclusive_group`. Each step must be run SEPARATELY:
```bash
$GSETUP --client-secret /path/to.json   # Step 1
$GSETUP --auth-url                       # Step 2 (separate command)
$GSETUP --auth-code "CODE"               # Step 3 (separate command)
```

There is no `--services`, `--format`, or other flag. The script is deliberately minimal.

## Working Authorization URL Pattern

Example of a successful auth URL generated by `$GSETUP --auth-url`:
```
https://accounts.google.com/o/oauth2/auth?response_type=code&client_id=581943771814-4qq4uo8e9mm6m9keroavifng9hrp1p1f.apps.googleusercontent.com&redirect_uri=http%3A%2F%2Flocalhost%3A1&scope=...&state=...&code_challenge=...&code_challenge_method=S256&access_type=offline&prompt=consent
```

**Notes**:
- `redirect_uri=http://localhost:1` — the browser will fail to load this, which is expected
- User must copy the full redirected URL from the address bar
- The `code` parameter is what matters
