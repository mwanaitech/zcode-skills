# Consignes de Français Soutenu — CV / Documents Professionnels

Modes d'expression **interdits** dans tout document destiné à un recruteur, employeur ou lecteur professionnel.

---

## Pronoms et déterminants familiers

| Familier → | Formel |
|---:|---|
| ça | cela / tel / ledit |
| un mec / une nana | un candidat / une candidate / un individu |
| on (sens « les gens ») | les personnes / les professionnels / les apprenants |
| des gens | des personnes / des professionnels / des apprenants |

## Vérbes et expressions à éviter

| Familier → | Formel |
|---:|---|
| il y a (ex: "il y a 3 ans") | depuis (ex: "Depuis 2022") |
| faire (ex: "faire un cours") | dispenser / animer / encadrer / élaborer |
| mettre en place | élaborer / concevoir / développer / instituer |
| piloter | diriger / superviser / coordonner / encadrer |
| gérer | administrer / superviser / coordonner |
| garantir | veiller à / assurer / superviser |
| contribuer à | participer à / contribuer à (acceptable si suivi d'un nom abstrait) |
| donner un cours | dispenser / animer / enseigner |
| être en charge de | assurer / diriger / superviser |

## Connecteurs et transitions familiers

| Familier → | Formel |
|---:|---|
| du coup | par conséquent / ainsi / de surcroît |
| en fait | en réalité / effectivement / en effet |
| bref | en somme / pour résumer / en définitive |
| quand même | néanmoins / toutefois / malgré tout |
| en plus | en outre / de plus / par ailleurs |
| genre | par exemple / à titre illustratif |
| voilà pourquoi | c'est la raison pour laquelle / d'où |

## Noms et formulations "CV-comme"

| Banal → | Élevé |
|---:|---|
| CV professionnel | Curriculum vitae |
| Résumé | Synthèse |
| Projet perso. | Projet personnel |
| Expériences | Parcours professionnel / Expérience professionnelle |
| Compétences en informatique | Compétences techniques / Maîtrises informatiques |
| Aide | Assistance / Appui / Support |
| Truc | Élément / Aspect / Composante |
| Stage de fin d'études | Stage de césure / Stage de validation |

## Constructions syntaxiques à corriger

| Défaillante → | Correcte |
|---:|---|
| "Enseigne à des publics variés, du collège au lycée" | "à des publics variés, du collège au lycée, ainsi qu'en formation professionnelle" |
| "Mon approche conjugue X et Y pour faire de chaque apprenant..." | "Mon approche conjugue X et Y afin de transformer chaque apprenant en..." |
| "Accompagnement vers l'autonomie" | "Accompagnement en vue de l'autonomie" / "en vue de l'acquisition de compétences autonomes" |
| "Très bon niveau en anglais" | "Anglais : courant / Anglais : technique" |
| "J'ai travaillé sur" | "J'ai contribué à" / "J'ai participé à" / "J'ai œuvré au sein de" |

## Checklist pré-envoi

Réviser le document final ligne par ligne pour :
- [ ] Zéro occurrence de "ça" (sauf dans une citation)
- [ ] Zéro tiret dans le prénom/nom (sauf si demandé par l'utilisateur)
- [ ] Zéro formulation du registre oral/familier
- [ ] Verbes d'action formels exclusifs (dispenser, encadrer, superviser, élaborer, concevoir...)
- [ ] Connecteurs soutenus (par conséquent, en outre, néanmoins...)
- [ ] Absence de "il y a" pour exprimer le temps
- [ ] Titres de section en majuscules avec accentuation correcte (Compétences, non Competences)
