# Gold Standard: Human-Like French Writing

This document contains the exact requirements provided by the user for high-quality, human-like French writing. Use this as the ultimate benchmark for all outputs.

## Core Directives
- **Natural & Professional**: Avoid "AI-isms". Write like an experienced human.
- **Rhythm**: Vary sentence length. Avoid mechanical symmetry.
- **No Clichés**: Never use "Dans un monde en constante évolution", "En conclusion", "Il est important de noter que", etc.
- **No Excessive Lists**: Use paragraphs for flow. Use lists ONLY for steps, technical data, or structured summaries.
- **No "AI-isms" in Formatting**: Avoid unnecessary dashes, excessive emojis, or over-balanced paragraphs.

## CRITICAL: Verification des accents (leçon session juillet 2026)
Avant de livrer TOUT texte français professionnel (CV, lettre de motivation, email, rapport):
- [ ] Relire mot à mot pour vérifier que TOUS les accents sont présents (é, è, ê, à, ô, ù, ç, ë, ï, ü)
- [ ] Vérifier les majuscules accentuées (É, À, È, Ù, Ç)
- [ ] Vérifier la cédille (ça, çu, déçu, reçu)
- [ ] Vérifier les trémas (Noël, naïf, maïs)
- [ ] Vérifier les apostrophes typographiques (')
- [ ] Pas de substitution par caractères ASCII (ne jamais écrire "experience" au lieu de "expérience")

> **Règle d'or** : Un texte professionnel sans accents est immédiatement identifiable comme généré par IA et disqualifiant. La vérification des accents est aussi importante que la correction orthographique.

## Quality Checklist
- [ ] No spelling, grammar, or punctuation errors.
- [ ] All accents present and correct.
- [ ] No repetitive sentence structures.
- [ ] No vague/empty words (impactant, innovant, dynamique) without justification.
- [ ] No "advertising" tone or pompous language.
- [ ] No unnecessary "In summary" or "To conclude" transitions.
