## Kanban multi-agent (configure 2026-06-30, mis a jour meme jour)

- `kanban.dispatch_in_gateway: true` active
- Board : `~/.hermes/kanban.db`
- 11 profiles reconnus par Kanban : api-designer, code-reviewer, default, devops-engineer, ecommerce-manager, education-manager, finance-manager, image-processor, marketing-manager, refactorer, ui-ux-designer
- Dispatcher manuel via `--assignee <profile>` et `--parent` pour dépendances

### Limitation connue

`kanban decompose` échoue avec les modèles gratuits (DeepSeek V4 Flash Free). Solution : créer sous-tâches avec `--parent`.

### Commandes

```bash
hermes kanban daemon --interval 30 --verbose   # lancer le dispatcher
hermes kanban create --assignee <profile> --skill <slug> "tâche"
hermes kanban create --assignee <profile> --skill <slug> --goal "tâche longue"
hermes kanban list
hermes kanban tail t_<id>
hermes kanban archive t_<id> t_<id2>
```
