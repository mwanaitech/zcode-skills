# Business Analysis Skill

## 目的

提供系统性的商业分析能力，输出专业、结构化的分析报告。核心覆盖两大场景：

1. **商业模式分析**：拆解企业价值主张、客户细分、收入模型、成本结构等要素
2. **行业深度报告**：研究市场规模、增长驱动、竞争格局、行业趋势与风险

## 触发场景

- "分析 X 公司的商业模式"
- "帮我写一份 X 行业的研究报告"
- "这家公司怎么赚钱？"
- "分析一下这个赛道的竞争格局"
- "我要投资 X，帮我做个尽调"
- "比较 A 和 B 公司的差异"

## 分析流程

### 第一步：明确分析目标

在开始分析前，先确认：
- **分析对象**：公司名称、产品/业务线、行业领域
- **分析目的**：投资决策 / 战略规划 / 竞品研究 / 学习了解
- **信息来源**：用户提供的材料 + 网络公开信息（优先用用户提供的资料）
- **分析深度**：快速概览（500字）/ 标准报告（2000字）/ 深度研究（5000字+）

### 第二步：选择分析框架

根据分析类型加载对应参考文档：

| 分析类型 | 参考文档 | 核心框架 |
|---------|---------|---------|
| 商业模式分析 | `references/business-model-frameworks.md` | BMC画布、价值链、飞轮效应 |
| 行业深度报告 | `references/industry-research-frameworks.md` | PEST、波特五力、市场地图 |
| 竞争对手分析 | `references/competitive-analysis-frameworks.md` | SWOT、定位矩阵、差异化对比 |

### 第三步：信息收集

- 使用 WebSearch 搜索最新的公司/行业信息（财报、新闻、研报）
- 搜索关键词格式：`{公司名} 商业模式 2025` / `{行业} 市场规模 最新`
- 优先引用权威来源：官方公告、行业协会数据、知名研报

### 第四步：撰写分析报告

根据分析类型使用对应的报告模板：
- 商业模式报告：见 `references/business-model-frameworks.md` → 报告模板部分
- 行业深度报告：见 `references/industry-research-frameworks.md` → 报告模板部分

**写作原则**：
- 数据驱动：每个判断都有数据支撑
- 结构清晰：使用标题层级、表格、要点列表
- 洞见为王：不止描述现象，要解释原因和影响
- 语言精准：避免模糊表述，用具体数字替代"大幅增长"等词

### 第五步：输出与呈现

- 标准报告直接以 Markdown 格式输出
- 复杂报告可生成 HTML 可视化版本（用 preview_url 展示）
- 包含数据对比时，优先使用 show_widget 生成内联图表
- 最终报告可用 deliver_attachments 作为附件交付

## 质量检查清单

在输出报告前，确认：
- [ ] 核心数据已标注来源或说明为估算
- [ ] 分析结论与数据逻辑一致
- [ ] 涵盖用户关心的核心问题
- [ ] 结构层次分明，可快速定位关键信息
- [ ] 包含可操作的结论或建议

## 注意事项

- 若信息不足，明确说明假设前提，而非凭空编造数据
- 涉及财务预测时，务必标注"仅供参考，非投资建议"
- 分析中国市场时，注意使用人民币（¥/CNY）和中国市场惯例
