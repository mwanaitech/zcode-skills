# Tolérance zéro accents — Exigence professionnelle absolue

## Contexte
L'utilisateur a exprimé de la frustration explicite ("Arrête de me fatiguer") lorsqu'un livrable français a été envoyé avec des accents manquants ("equipe" au lieu de "équipe", "experience" au lieu de "expérience", etc.).

## Nature de l'exigence
Ce n'est **pas** une préférence stylistique mineure. C'est une **exigence professionnelle absolue** :
- Le texte français DOIT être relu systématiquement pour tous les accents avant livraison.
- Aucun texte ne sort en « brouillon rapide » ou « version temporaire ».
- La vérification des accents est un **point de non-retour** obligatoire dans le workflow.

## Mots à surveiller impérativement
| Incorrect | Correct |
|---|---|
| equipe | équipe |
| experience | expérience |
| competences | compétences |
| developpe | développé |
| securite | sécurité |
| utilisateur | utilisateur |
| materiel | matériel |
| telephone | téléphone |
| procedures | procédures |
| reseau | réseau |
| fonction | fonction |
| motivation | motivation |
| interesse | intéressé |
| curriculum | curriculum |

## Mécanisme de vérification recommandé
1. Relire chaque mot accentué dans le texte final.
2. Re-relire une deuxième fois systématiquement (double passage).
3. Ne jamais utiliser de « livraison rapide » comme excuse pour raccourcir cette étape.
