# 04-ui-to-design-system｜UI 到设计系统

## 模块定位

这是 Design UI Prototype Expert Pack 的内部路由模块，不是面向普通用户的独立入口。只有当总控技能判断用户任务处于「UI 到设计系统」阶段时才调用。

## 输入

- 用户原始需求、PRD、原型描述或上一阶段输出。
- 总控技能给出的默认假设、页面范围和交付物要求。
- 必要时读取外层 `references/quick-start.md`、`references/output-templates.md` 和 `references/qa-checklist.md`。

## 执行要求

1. 只处理本阶段职责，不扩展无关能力。
2. 保持输出可被下一阶段继续使用。
3. 对缺失信息给出最小追问或默认假设。
4. 所有建议必须落到页面、流程、模块、字段、组件、状态、交互或验收项。
5. 不承诺生产级代码、上线质量或像素级设计稿还原。

## 输出

- 本阶段结论
- 可传递给下一模块的结构化结果
- 缺口与待确认事项
- 本阶段 QA 检查点

## 完成标准

- 产物能支持总控技能合并进最终交付。
- 没有暴露不必要的内部术语给普通用户。
- 没有生成与本阶段无关的冗余文件或说明。
